# PMN Plotter

Aplikasi HP (PWA) untuk membaca Port Marine Notice (PMN) MPA Singapura, memeriksa koordinatnya di peta, dan menyiapkan berkas untuk ECDIS. Antarmuka berbahasa Indonesia dan Inggris.

Halaman ini hanya berisi aplikasi statis. Tidak ada data kapal, alamat server, atau kode akses di dalamnya: alamat server dan kode diisi sekali di HP lewat tombol ⚙ (Pengaturan) dan hanya disimpan di perangkat itu. Tanpa keduanya aplikasi berjalan dalam mode demo dengan data contoh.

Peta hanya ilustrasi, bukan untuk navigasi. User chart adalah informasi tambahan, bukan koreksi resmi ENC.
